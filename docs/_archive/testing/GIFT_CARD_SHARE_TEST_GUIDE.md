# 购物卡分享与领取完整测试指南

## 测试环境准备

### 1. 确保后端PHP GD库已启用
```bash
# 检查GD库是否可用
php -m | grep gd
```

如果GD库未启用，需要在 `php.ini` 中启用：
```ini
extension=gd
```

### 2. 确保上传目录可写
WordPress上传目录下的 `giftcards` 子目录需要可写权限：
```bash
# 检查目录权限
ls -la wp-content/uploads/giftcards
```

## 完整测试流程

### 场景一：在线分享二维码测试

#### 步骤1：购买购物卡
1. 使用账号A登录小程序
2. 进入"购物卡中心" → "购买购物卡"
3. 选择任意购物卡模板，完成购买
4. 等待订单完成（或手动将订单状态改为"已完成"）

#### 步骤2：分享购物卡
1. 进入"购物卡中心" → "我的购物卡"
2. 点击"分享/赠送"按钮
3. 在购物卡列表页选择要分享的购物卡
4. 在订单详情确认页查看详情，点击"确认分享"
5. 在分享设置页：
   - 选择一个分享模板样式
   - 编辑祝福语（可选）
   - 点击"确认"
6. 在分享结果页：
   - 应该看到带模板图案的二维码图片（包含卡片信息、金额、祝福语）
   - 点击"分享电子二维码"
   - 图片预览界面打开，长按图片可以保存或分享

#### 步骤3：领取购物卡（账号B）
1. 使用账号B登录小程序（或新注册账号）
2. 在微信中打开账号A分享的二维码图片
3. 长按识别二维码
4. 应该跳转到小程序登录页面（如果未登录）
5. 登录后自动跳转到领取确认页
6. 查看购物卡信息（金额、祝福语等）
7. 点击"确认领取并保存"
8. 自动跳转到"我的"页面，显示购物卡数量

#### 步骤4：验证领取结果
1. 使用账号B进入"购物卡中心" → "我的购物卡"
2. 应该能看到领取的购物卡
3. 点击"管理购物卡"查看详细信息
4. 可以继续分享或兑换商品

### 场景二：扫码保存的二维码图片领取

#### 步骤1：保存二维码图片
1. 按照场景一的步骤1-2操作，直到分享结果页
2. 点击"保存购物卡"按钮
3. 授权相册权限（如果需要）
4. 图片保存到手机相册

#### 步骤2：扫码领取
1. 使用账号B（或新账号）打开微信
2. 使用微信扫一扫功能扫描保存的二维码图片
3. 应该跳转到小程序登录页面（如果未登录）
4. 登录后自动跳转到领取确认页
5. 后续流程与场景一相同

## 测试检查点

### 功能检查
- [ ] 购物卡列表页只显示可分享的购物卡
- [ ] 点击购物卡跳转到订单详情确认页
- [ ] 订单详情页正确显示金额和产品信息
- [ ] 分享设置页可以选择模板和编辑祝福语
- [ ] 分享结果页显示带模板图案的二维码图片
- [ ] 二维码图片包含：卡片名称、金额、祝福语、二维码
- [ ] 分享电子二维码功能正常（预览图片）
- [ ] 保存购物卡功能正常（保存到相册）
- [ ] 扫码/长按识别二维码能正确跳转
- [ ] 未登录用户扫码后跳转到登录页
- [ ] 登录后自动跳转到领取确认页

- [ ] 领取后购物卡 `redeemer_id` 更新为领取用户

- [ ] 自己分享给自己的购物卡不能领取

## 常见问题排查

### 1. 二维码图片没有显示
- 检查PHP GD库是否启用
- 检查上传目录权限
- 查看后端错误日志

### 2. 图片生成失败
- 检查字体文件是否存在
- 检查网络连接（下载在线二维码）
- 查看PHP错误日志

### 3. 扫码无法跳转
- 检查二维码内容是否正确（应该是 `myshop://giftcard?token=xxx`）
- 检查小程序配置的URL Scheme
- 检查微信开发者工具设置

### 4. 领取失败
- 检查token是否有效
- 检查购物卡状态
- 检查用户权限

## 测试数据清理

测试完成后，可以清理测试数据：
```sql
-- 清理测试购物卡
DELETE FROM wp_myshop_gift_cards WHERE card_number LIKE 'GC%';

-- 清理测试订单
DELETE FROM wp_posts WHERE post_type = 'shop_order';
```

## 注意事项

1. **二维码有效期**：分享token默认7天有效，过期后无法领取
2. **图片存储**：生成的二维码图片存储在 `wp-content/uploads/giftcards/` 目录
3. **字体支持**：如果系统没有中文字体，文字可能显示为方块，但不影响二维码识别
4. **网络依赖**：当前实现依赖在线二维码生成服务，需要网络连接

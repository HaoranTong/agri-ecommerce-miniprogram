# 微信开发者工具多账户测试指南

## 方法一：使用真机调试（推荐）

### 步骤1：准备两部手机
1. 手机A：登录账号A（购买购物卡的用户）
2. 手机B：登录账号B（领取购物卡的用户）

### 步骤2：开启真机调试
1. 在微信开发者工具中，点击工具栏的"预览"按钮
2. 选择"真机调试"
3. 用手机A扫描二维码，进入小程序
4. 在手机A上完成购买和分享操作

### 步骤3：分享给手机B
1. 在手机A上完成购物卡分享，生成二维码图片
2. 将二维码图片发送给手机B（通过微信、邮件等方式）
3. 手机B长按识别二维码或使用微信扫一扫
4. 手机B登录账号B，完成领取流程

### 优点
- ✅ 完全真实的用户体验
- ✅ 可以测试真实的扫码、长按识别等功能
- ✅ 可以测试真实的微信登录流程
- ✅ 可以测试真实的分享功能

### 缺点
- ❌ 需要两部手机
- ❌ 需要两个不同的微信账号

---

## 方法二：使用微信开发者工具模拟器（快速测试）

### 步骤1：在开发者工具中切换账号
1. 在微信开发者工具中，点击右上角的"清缓存" → "清除数据缓存"
2. 在代码中临时修改登录逻辑，使用不同的测试账号
3. 或者使用开发者工具的"模拟器"功能，但功能有限

### 步骤2：模拟分享流程
1. 使用账号A登录，购买购物卡
2. 分享购物卡，获取二维码URL或图片
3. 在浏览器中打开二维码URL，保存图片
4. 清除小程序缓存，切换到账号B
5. 使用账号B登录，手动输入分享token或使用二维码

### 限制
- ⚠️ 无法真实测试扫码功能
- ⚠️ 无法真实测试长按识别功能
- ⚠️ 需要手动切换账号和清除缓存

```typescript
  // 添加测试账号列表
  const testAccounts = [
    { username: 'test001', password: 'password1' },
    { username: 'test002', password: 'password2' }
  ];
  
  // 在登录页面添加快速切换按钮
}
```

### 步骤2：使用两个浏览器窗口
1. 打开两个浏览器窗口，分别访问小程序
2. 窗口A：登录账号A，完成购买和分享
3. 窗口B：登录账号B，完成领取
4. 将窗口A生成的二维码图片复制到窗口B

### 优点
- ✅ 可以快速切换账号
- ✅ 不需要真实手机
- ✅ 适合开发阶段快速测试

### 缺点
- ❌ 无法测试真实的扫码功能
- ❌ 需要手动复制二维码

## 方法四：使用微信开发者工具 + 真机预览组合（最佳实践）

### 步骤1：开发者工具用于开发
- 在开发者工具中完成代码开发和调试
- 使用模拟器测试基本功能

### 步骤2：真机预览用于完整测试
- 使用真机预览功能，在真实手机上测试

### 步骤3：测试流程
1. **开发阶段**：使用开发者工具模拟器，快速验证功能
2. **联调阶段**：使用真机预览，在真实环境中测试
3. **完整测试**：使用两部手机，完成端到端测试

## 常见问题

### Q1: 如何在开发者工具中清除登录状态？
**A:** 点击工具栏的"清缓存" → "清除数据缓存"，或者在小程序中调用 `Taro.clearStorage()`

### Q2: 真机调试时如何查看日志？
**A:** 在开发者工具中，点击"真机调试"，可以看到真机的控制台日志

### Q3: 如何获取分享的二维码URL？
**A:** 在分享结果页面，查看浏览器控制台，可以看到 `qr_image_url` 的值

### Q4: 测试时如何快速切换账号？
**A:** 可以在代码中添加测试账号快速切换功能，或者使用两个浏览器窗口

## 注意事项

1. **真机调试需要网络连接**：确保手机和电脑在同一网络，或者使用局域网IP
2. **分享token有效期**：默认7天，测试时注意时间限制
3. **清除缓存**：切换账号前记得清除缓存，避免数据混淆
4. **API域名配置**：确保真机调试时，API域名已配置到微信小程序后台

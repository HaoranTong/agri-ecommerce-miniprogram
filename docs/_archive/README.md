## 分类目录

- `plans/`：规划与方案
- `status/`：状态与里程碑总结
- `analysis/`：分析/问题/理解总结
- `testing/`：测试指南与测试记录
- `specs/`：被新版本替代的规范/规格
- `dev_notes/`：实施细节/开发记录
- `scripts/`：一次性脚本与手工操作指引
- `security/`：敏感信息（建议移出仓库并轮换）

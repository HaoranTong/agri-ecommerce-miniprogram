## 🐛 常见问题排查

### 1. 编译错误
```powershell
# 清除缓存重新编译
rm -rf dist node_modules
npm install
npm run dev:weapp
```

### 2. API 请求失败
- 检查后端是否运行
- 检查 Token 是否有效
- 查看 Network 面板详细错误
- 确认 `urlCheck` 已关闭

### 3. 页面空白/报错
- 打开调试器查看 Console
- 检查组件导入路径
- 确认 TypeScript 无类型错误

### 4. 数据不显示
- 检查后端数据库是否有测试数据
- 确认 API 返回格式正确
- 查看 Network 请求响应

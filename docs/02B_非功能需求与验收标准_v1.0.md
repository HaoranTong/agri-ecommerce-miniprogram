# 非功能需求与验收标准（V1.0）

> **定位**：本文件是非功能需求与验收标准的唯一出处。其他文档只能引用，不得重复定义。
> **范围**：性能、可用性、稳定性、安全、兼容性、可维护性、可观测性。

---

## 一、性能要求

| 项 | 指标 | 验收方式 |
| --- | --- | --- |
| 首页加载 | 首屏 ≤ 2s | 真机网络环境测试 |
| 列表渲染 | ≤ 500ms | 低端机型性能面板 |
| 接口响应 | P95 ≤ 200ms | 后端日志/压测 |
| 图片加载 | 首屏关键图 ≤ 2s | 真机测试 |

---

## 二、可用性与稳定性

| 项 | 指标 | 验收方式 |
| --- | --- | --- |
| 可用性 | 核心功能可用率 ≥ 99.5% | 线上监控统计 |
| 崩溃率 | ≤ 0.2% | 小程序错误监控 |
| 失败重试 | 关键写接口可重试 | 断网/弱网测试 |

---

## 三、安全要求

| 项 | 指标 | 验收方式 |
| --- | --- | --- |
| 认证 | 写操作必须校验 JWT | 接口测试 |
| 敏感数据 | 不落地明文 PIN/密码 | 代码审查 |
| 输入校验 | 所有输入进行过滤 | 安全测试 |
| 审计 | 关键操作写审计日志 | 数据核查 |

---

## 四、兼容性要求

| 项 | 指标 | 验收方式 |
| --- | --- | --- |
| 设备 | iOS 12+ / Android 8+ | 真机覆盖测试 |
| 基础库 | ≥ 2.24.0 | 开发者工具检查 |
| 网络 | 4G/5G/WiFi/弱网 | 网络切换测试 |

---

## 五、可维护性

| 项 | 指标 | 验收方式 |
| --- | --- | --- |
| 结构规范 | 符合 `docs/10_MINIPROGRAM_SPEC_v2.0.md` | 代码检查 |
| 接口一致 | 接口字段与 `docs/08_API_CONTRACT_V2.3.md` 一致 | 自动/人工审查 |
| 数据一致 | 字段含义以 `docs/06_DATA_DICTIONARY_v1.2.md` 为准 | 文档校验 |

---

## 六、可观测性

| 项 | 指标 | 验收方式 |
| --- | --- | --- |
| 错误追踪 | 关键错误可定位 | 日志与错误上报 |
| 关键链路 | 登录/下单/支付链路可追踪 | 日志检查 |

---

## 七、验收规则

1. 必须通过 `docs/16_测试用例文档.md` 中的核心用例。
2. 必须通过 `docs/17_QA_POSTMAN_CHECKLIST.md`。
3. 必须通过真机测试流程 `docs/14_REAL_DEVICE_DEBUG_GUIDE.md`。
4. 所有新增字段与接口必须更新 `docs/06_DATA_DICTIONARY_v1.2.md` 与 `docs/08_API_CONTRACT_V2.3.md`。

## 开发流程要求（AI 与开发者必须遵守）

- 严格遵循：用户需求 -> 产品需求 -> 架构设计 -> 技术实现 -> 测试 -> 文档与代码回归对齐
- 任一环节发现问题：先回到文档核对
	- 文档有问题：先修文档，再改代码，最后补测试
	- 代码有问题：按技术文档修代码，补清晰注释，最后补测试
- 新功能必须先写入文档并完成层级对齐，再开始编码
- 完成任一功能必须跑单元/接口测试，通过后再进入阶段性真机测试
- 以文档为唯一来源（API 契约/数据字典/模型），禁止口头或代码先行偏离

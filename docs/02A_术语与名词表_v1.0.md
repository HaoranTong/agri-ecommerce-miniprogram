# 术语与名词表（V1.0）

> **定位**：本文件是项目术语、名词与缩写的唯一解释来源。其他文档只能引用，不得重复定义。
> **适用范围**：需求、功能规格、架构、数据模型、API 契约、测试文档与代码实现。

---

## 一、业务术语

| 术语 | 说明 | 备注 |
| --- | --- | --- |
| 小程序 | 微信小程序客户端 | 以 Taro React 实现 |
| 后台 | WordPress 管理后台 | 包含 WooCommerce |
| 用户 | 终端用户（买家/受赠人） | 非运营人员 |
| 运营人员 | 后台管理员/运营角色 | 权限见 `docs/07_ROLE_MATRIX_v2.0.md` |
| 商品 | WooCommerce 商品 | 可能为变体商品 |
| 订单 | WooCommerce 订单 | 状态以 `docs/08_API_CONTRACT_V2.3.md` 为准 |
| 购物车 | 用户待购买商品集合 | 数据存放在 `user_meta.cart_items` |
| 购物卡 | 虚拟购物卡（储值或商品兑换） | 类型见数据模型与 API 契约 |
| 分享 | 购物卡转赠行为 | 需通过 share_token 或二维码 |
| 领取 | 受赠人绑定购物卡 | 绑定后 share_token 失效 |
| 兑换 | 使用购物卡抵扣/换购 | 可能生成 0 元订单 |
| 积分 | 用户积分余额与流水 | 受积分规则约束 |
| 分销 | 邀请关系与佣金体系 | 以邀请码/渠道归因 |
| 代理 | 区域代理体系 | 具备独立权限与仪表盘 |
| 运营配置 | Banner/规则/任务/模板等配置 | 后台配置后由小程序读取 |

## 二、Postman接口测试指南

### 2.1 测试环境配置

**环境文件位置**: `docs/postman/MyShop_Dev.postman_environment.json`

**必需配置项**:
```json
{
  "BASE_URL": "https://agri-ecommerce.test",
  "API_PREFIX": "/wp-json/myshop/v1",
  "AUTH_TOKEN": "{{token}}"
}
```

### 2.2 核心测试流程

#### 步骤1: 认证测试
```bash
# 1. 获取微信登录code（开发工具中获取）
# 2. 调用登录接口
POST /auth/login
{
  "code": "test_code_here"
}

# 预期结果: 返回token和用户信息
# 状态码: 200
# 响应包含: token, user_id, openid
```

#### 步骤2: 业务功能测试
```bash
# 商品相关
GET /products                    # 获取商品列表
GET /products/redeem           # 获取积分兑换商品

# 订单相关  
POST /orders                   # 创建订单
GET /orders                    # 获取订单列表
POST /orders/{id}/upload-proof # 上传支付凭证

# 购物卡相关
GET /gift-cards                # 获取我的购物卡
POST /gift-cards/share         # 分享购物卡
POST /gift-cards/redeem        # 兑换购物卡

# 积分相关
GET /points/balance           # 获取积分余额
GET /points/ledger            # 获取积分流水
POST /points/spend            # 使用积分

# 代理相关
POST /agents/apply            # 申请代理
GET /agents/me               # 获取代理信息

# 分销相关
GET /invitations/summary      # 邀请统计
POST /invitations/track       # 渠道追踪
GET /analytics/channel        # 渠道分析
```

### 2.3 关键测试用例

#### 高优先级测试用例
1. **用户认证流程**
   - 正常登录 → 获取token → 访问受保护接口
   - 无效token → 401错误 → 跳转到登录页

2. **订单创建流程**
   - 创建普通订单 → 检查订单状态
   - 创建积分抵扣订单 → 验证积分扣减
   - 创建购物卡订单 → 验证购物卡生成

3. **支付流程测试**
   - 上传支付凭证 → 检查状态变更
   - 使用优惠券 → 验证金额计算
   - 使用购物卡 → 验证余额扣减

4. **购物卡功能测试**
   - 购买储值卡 → 检查卡号生成
   - 分享购物卡 → 检查分享链接
   - 兑换商品 → 检查0元订单

5. **积分系统测试**
   - 获取积分 → 检查余额显示
   - 积分流水 → 检查明细记录
   - 积分兑换 → 检查商品兑换

#### 自动化测试命令
```bash
# 安装 Newman
npm install -g newman

# 运行完整测试套件
newman run docs/postman/myshop-api-test-suite.postman_collection.json \
  -e docs/postman/MyShop_Dev.postman_environment.json \
  --reporters cli,junit \
  --reporter-junit-export test-results.xml

# 仅运行关键接口测试
newman run docs/postman/myshop-api-test-suite.postman_collection.json \
  -e docs/postman/MyShop_Dev.postman_environment.json \
  --folder "认证测试,订单测试,支付测试"
```

## 五、自动化测试配置

### 5.1 Jest单元测试配置

**配置文件**: `jest.config.js`
```javascript
module.exports = {
  testEnvironment: 'node',
  testMatch: ['**/src/**/__tests__/**/*.test.{js,ts,tsx}'],
  collectCoverageFrom: [
    'src/**/*.{js,ts,tsx}',
    '!src/**/*.d.ts',
    '!src/**/__tests__/**/*'
  ],
  coverageDirectory: 'coverage',
  coverageReporters: ['text', 'lcov', 'html']
};
```

**测试命令**:
```bash
# 运行所有测试
npm test

# 运行测试并生成覆盖率报告
npm run test:coverage

# 监视模式运行测试
npm run test:watch
```

### 5.2 CI/CD集成

**GitHub Actions配置**: `.github/workflows/test.yml`
```yaml
name: Test Suite
on: [push, pull_request]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Setup Node.js
        uses: actions/setup-node@v3
        with:
          node-version: '18'
      - name: Install dependencies
        run: npm install
      - name: Run unit tests
        run: npm test
      - name: Run API tests
        run: npm run test:api
      - name: Upload coverage
        uses: codecov/codecov-action@v3
```
